# Logo

An egg holding a small e-graph: an e-node whose two children sit in one e-class, the dashed pill, because
they have been proven equal. The badge is the .NET rounded square in `#512BD4`; the line work is white, and the
e-class and the node rewritten into it are `#C9BCF5`.

| file | use |
|---|---|
| `icon.svg` | the logo — package icon, avatar, favicon |
| `icon.png` | 512×512 raster of `icon.svg`; the copy at the repository root is the `PackageIcon` for every package |

Re-render `icon.png` after changing `icon.svg`, and copy it over the one at the root. Any browser will do, e.g.
headless Edge: `msedge --headless=new --default-background-color=00000000 --window-size=512,512
--screenshot=icon.png <page showing icon.svg at 512×512>`.
